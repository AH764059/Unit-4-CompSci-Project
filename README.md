Project Overview/Introduction:
This is my CompSci Unit 4 Project, "Newton's Apples".

The project is a "dodge the falling objects" style game. The player is able to
move left ot right via the left/right arrow keys, to jump via the up arrow key,
to shrink but lose speed via the down arrow key. The project also saves the high
score on a txt file, as well as the username of the player who achieved the high
score, on different txt file.

To run this program, select NewtonAppleDodgeGame.java as the main file.

My goal for this project was to better understand how to work with Java Swing.
